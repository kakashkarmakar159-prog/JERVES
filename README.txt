# JARVIS Personal Assistant — Starter Website

## Run it
1. Extract the ZIP.
2. Open the `JARVIS` folder in VS Code.
3. Open `index.html` with a local server (VS Code Live Server is convenient), or open it directly in a browser.
4. For best voice support, use a supported browser such as Chrome and allow microphone access.

## Included
- Responsive futuristic dashboard
- Local starter chat (not a full AI model)
- Voice input where browser speech recognition is supported
- Tasks, notes, theme and preferences saved in browser local storage
- App shortcuts, limited battery status support and web notification permission prompt

## Important limitations
A normal website cannot control all Android functions, read all phone notifications, silently launch arbitrary apps, or toggle protected system settings. Those features require a separate Android companion app, Android permissions and user consent. This website is the first UI prototype; it does not include a cloud AI API or paid service. Advanced AI can be connected later, but online APIs may have usage limits or charges. Local AI requires a compatible model and enough device resources.

No passwords, API keys or sensitive credentials should be placed in frontend JavaScript.
